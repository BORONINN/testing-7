# Практическая работа 7

Вариант 1. Каталог товаров OWASP Juice Shop.

Объект тестирования: каталог товаров. Проверяются отображение списка, сведения о выбранном товаре каталога, поиск в каталоге и навигация по его страницам.

Репозиторий: https://github.com/BORONINN/testing-7

```bash
git clone https://github.com/BORONINN/testing-7.git
cd testing-7
```

## Запуск

Требуется Node.js 24 с npm и запущенный Juice Shop по адресу http://127.0.0.1:3000.

```bash
npm ci
npx playwright install chromium
npm test
```

Проект проверен с Playwright 1.65.1, Chromium и Juice Shop 20.4.0-SNAPSHOT на macOS arm64. В каталоге 46 товаров, размер первой страницы 15. Тесты используют английский интерфейс и часовой пояс Europe/Moscow. Перед запуском убедитесь, что тестовые товары не изменены.

Конфигурация локального Juice Shop находится в папке `app`. Для запуска через Docker Desktop:

```bash
docker compose -f app/compose.yaml up -d
```

Образ закреплён по digest. Порт опубликован только на 127.0.0.1.

## Сценарии каталога товаров

- Отображение товаров в каталоге: C01 количество карточек, C02 цена, C03 загрузка изображения.
- Просмотр сведений о товаре из каталога: D01 название, D02 описание, D03 цена, D04 закрытие.
- Поиск товаров в каталоге: S01 полное название, S02 часть названия, S03 регистр, S04 пустая выдача, S05 очистка.
- Навигация по страницам каталога: P01 недоступность Previous на первой странице, P02 Next, P03 Previous, P04 размер 30 с клавиатуры, P05 открытие выбора количества товаров мышью.

Каждый тест получает отдельный браузерный контекст. Сценарии не создают аккаунты и не меняют товары. Проверки используют ожидания Playwright без фиксированных пауз. `retries: 0` не скрывает ошибки повторными попытками. Для падений сохраняются screenshot и trace.

## Отчёты

Для публикации отчётов через GitHub Pages владелец репозитория выбирает Settings > Pages > Source > GitHub Actions. Затем в Actions запускается workflow `Publish test reports` через Run workflow. При последующих изменениях папки `reports` в `main` публикация запускается автоматически.

После успешного развёртывания общая страница будет доступна по адресу https://boroninn.github.io/testing-7/, итоговый отчёт по адресу https://boroninn.github.io/testing-7/final/.

- `reports/final`: итоговый прогон, 16 passed, 1 failed. P05 завершился тайм-аутом при клике мышью по Items per page; сохранены screenshot и trace.
- `reports/initial`: первый прогон, 15 passed, 1 failed. P04 не смог кликнуть по размеру страницы: слой `mat-mdc-paginator-touch-target` перехватывает указатель. Исходная версия тестов сохранена в `test-snapshots/catalog.initial.js`.
- `reports/demo`: учебный прогон, 15 passed, 1 failed. В C01 намеренно задано неверное ожидание 16 вместо 15.

```bash
# Открыть итоговый отчёт
npx playwright show-report reports/final --host 127.0.0.1 --port 9323

# Открыть исходный отчёт с падением P04
npx playwright show-report reports/initial --host 127.0.0.1 --port 9325

# Воспроизвести учебное падение C01 (команда ожидаемо завершается с кодом 1)
DEMO_FAILURE=1 npx playwright test --grep-invert 'P05'
npx playwright show-report reports/demo --host 127.0.0.1 --port 9324

# Общая страница с тремя отчётами, если установлен Python 3
python3 -m http.server 9323 --bind 127.0.0.1 --directory reports
```

При запуске общей страницы откройте http://127.0.0.1:9323/. Не запускайте два сервера одновременно на одном порту. Остановить сервер можно Ctrl+C.

Повторный `npm test` заменяет `reports/final` и `results/final.json`. Перед повторным запуском сохраните старый отчёт, если он нужен. Для передачи преподавателю архивируйте всю папку отчёта вместе с `data` и `trace`, а не один index.html. Адрес 127.0.0.1 доступен только на компьютере, где запущен сервер. HTML-отчёты хранятся в репозитории. Для просмотра скачайте проект и запустите сервер отчётов по инструкции выше.

## Разбор результатов

В P04 клавиатурное открытие списка через Enter работает и позволяет выбрать 30 товаров. Это проверка клавиатурного пути, а не доказательство исправления перехвата клика. Исходная проблема требует отдельной проверки мышью и не скрыта из материалов.

В учебном C01 ошибка находится в ожидании теста: интерфейс показывает размер страницы 15, а проверка ожидает 16. После возврата правильного ожидания C01 проходит. Это не дефект Juice Shop.

Итоговый прогон включает 17 сценариев в Chromium: 16 прошли, P05 упал. Команда `npm test` завершается с кодом 1, пока P05 воспроизводит проблему. Мобильные устройства, другие браузеры, доступность, корзина и безопасность в объём этой работы не входят.
